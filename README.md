# 🛍️ Retail IQ – E-commerce Sales Analytics Dashboard
# 📌 Project Overview

**Retail IQ** is an end-to-end E-commerce Sales Analytics project developed to analyze customer purchasing behavior, sales performance, product trends, and revenue patterns.

Using a dataset containing **20,000+ e-commerce transactions**, this project demonstrates the complete analytics workflow:

- Data Cleaning & Preparation
- Exploratory Data Analysis (EDA)
- SQL-Based Business Analysis
- Data Visualization
- Interactive Power BI Dashboard Development
- Business Insight Generation

The objective of this project is to convert raw transactional data into meaningful business intelligence that can support data-driven decision-making.

---

# 🎯 Business Objectives

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Evaluate payment method preferences.
- Discover high-revenue cities and customer segments.
- Monitor revenue trends over time.
- Generate actionable business insights using data.

# 📂 Dataset Information

The dataset consists of **20,000+ E-commerce Transactions** containing the following fields:

| Column Name | Description |
|------------|-------------|
| customer_id | Unique Customer ID |
| order_id | Unique Order ID |
| order_date | Date of Purchase |
| city | Customer City |
| category | Product Category |
| product_name | Product Name |
| quantity | Quantity Purchased |
| order_value | Revenue Generated |
| payment_method | Payment Method Used |
